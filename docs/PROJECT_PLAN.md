# Pmagic AI 产品官网还原计划

## 1. 项目目标

依据 `reference/site-reference.jpg` 制作一个可独立部署的产品官网：

- 桌面端高度还原参考图的布局、比例、色彩、层级和视觉节奏。
- 平板与手机端采用真实响应式布局，不做整页等比缩放。
- 复杂配图重新生成或重绘为高清素材，并保持统一的蓝紫色半透明 3D 风格。
- 页面内容使用语义化 HTML、CSS 和必要的 JavaScript。
- 最终结果兼顾视觉一致性、加载性能、可维护性与可访问性。

## 5. 响应式策略

- 桌面宽屏（≥ 1200px）：忠实恢复参考图的主要栅格和双栏关系。
- 平板（768–1199px）：四列转两列，复杂双栏适度压缩或上下排列。
- 手机（< 768px）：导航收起；Hero、架构、案例和资源区改为纵向；复杂卡片可横向滚动。
- 字号、间距和插画尺寸优先使用 `clamp()`、Grid、Flexbox 与容器查询。
- 精确断点可在首轮桌面实现后依据内容压力测试调整。

## 7. 验收原则

- 桌面端以事实源叠图或并排截图进行逐区比较。
- 先验收结构和比例，再验收素材，最后验收细节和响应式。
- “像素级”适用于原图明确给出的桌面视觉；移动端按设计一致性和可用性验收。
- 生成式素材允许纹理细节不同，但主体结构、构图位置、色彩、材质和光照方向必须一致。
